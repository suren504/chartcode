# 绘图代码

这是一个供 Agent 使用的制图库，目前包含表格杠铃图、桑基图和蜂群图。用户只需提供原始数据，可以保留原有列名和格式。用户指定图型时，Agent 按指定图型制作；其余情况下，Agent 根据数据结构和表达目标自动选图，再确定当次的标题、图注、单位和素材。

每种模板提供 macOS 的 Swift/AppKit 版和 Windows 的 Python/Pillow 版。同种图型共用绘图输入约定，Agent 根据运行环境选择脚本。Python 依赖见 `requirements.txt`。

## Agent 工作流程

1. **理解数据。** 识别每行代表的对象、指标含义、单位、统计范围和对比关系。结合用户给出的标题或用途判断要强调的是分布、差距、排名、变化还是关系。
2. **确定图型。** 用户指定图型时优先采用。默认按任务自动选择。每个对象有一个数值、重点在分布和聚集时用蜂群图。同一对象有两项可共用刻度的数值、重点在差距时用表格杠铃图。总量可逐层拆成互斥类别、重点在比较构成时用桑基图。侧重名次时可用排序条形图，侧重时间变化时可用折线图。按数据需要选择图型。
3. **准备当次输入。** Agent 负责字段映射、排序、文案、环境选择和运行步骤，按所选脚本的内部约定在临时目录整理数据。图表可以复用已有素材。数据口径或方向确实无法推断时，先确认会影响图意的部分。
4. **生成并检查。** 检查数据映射、排序、刻度、方向、素材和文字裁切后交付图片。默认采用轻量的本地验证，浏览器验证按用户明确要求执行。

## 表格杠铃图

用 `表格杠铃图.py` 调用绘图。macOS 默认优先使用 Swift/AppKit，Swift 不可用或执行失败时回退到 Python/Pillow。Windows 使用 Python/Pillow。可用 `--engine swift` 或 `--engine python` 指定引擎。Python 引擎所需依赖见 `requirements.txt`。

Agent 根据所比较的两组数据准备当次绘图输入和配置，差值按两项原始数值计算。表头和图注文案随任务设置。有球队 Logo 或球员头像时可用它们作为标记，也支持空心圆标记。

```bash
python3 表格杠铃图.py /临时目录/绘图输入.json /输出目录 --config /临时目录/当次配置.json
```

macOS 也可直接运行 `swift 表格杠铃图.swift /临时目录/绘图输入.json /输出目录 /临时目录/当次配置.json`。省略输出目录时，图片写入绘图输入文件所在目录。模板导出 `表格杠铃图.png`（报纸背景）和 `表格杠铃图_透明.png`。

### 排版与样式

| 项目 | 规则 |
| --- | --- |
| 画布 | 宽 1452 点，高 `184 + 行数 × 54` 点，2 倍像素导出 |
| 布局 | 左侧表格、右侧共享横轴杠铃图，内容左边距 40 点 |
| 标题 | 32 号加粗，顶部 17 点，按可见字形修正左侧留白 |
| 副标题 | 16 号加粗，顶部 68 点，与标题可见左边缘对齐 |
| 表头与刻度 | 11 号，表头顶部 129 点，底线 159.5 点 |
| 行距 | 54 点，第一行中心 Y=187 点 |
| 对象名称 | 最大 13 号加粗，过长时按名称区宽度缩小 |
| 两项数值 | 13 号常规字重，右对齐 |
| 两项差值 | 17 号加粗，右对齐，正值带 `+` |
| 字体 | macOS 优先 Menlo／苹方，Windows 使用 Consolas／微软雅黑 |
| 颜色 | 主文字 `#2C3E50`，次文字 `#566473`，细分隔线 |
| 排序与配色 | 原始差值降序，按组内排名由绿到灰到红 |
| 头像或 Logo | 左表 34 点，图表圆框约 42 点，内图 40 点。一个端点全显，另一个半透明 |
| 连线 | 3 点粗，两端按真实数值定位。差值接近时可重叠，坐标保持原值 |
| 背景 | 先生成透明前景，再平铺报纸纹理，叠加白色调淡后合成 |

## 桑基图

`桑基图.swift` 和 `桑基图.py` 适合比较多个对象的两级构成。每张分图从左到右显示总量、两个分组及各自子类。两个分组最多共用六个子类，同一张图里的各分图使用同一流带厚度刻度。默认每行四张、背景为 `#F3F4F5`。

Agent 根据用户数据在临时目录准备绘图输入。子类应互斥且可加总。原始数据已有总量或小计时，先核对其与子类加总一致。脚本按输入顺序排图，从子类数值计算各分组和总量。

| 输入字段 | 约定 |
| --- | --- |
| `title`、`totalLabel` | 主标题和最左侧总量标签 |
| `subtitle`、`credit` | 可选的图注和加粗署名 |
| `language`、`columns` | 可选字体方案 `zh-Hans`、`zh-Hant` 或 `en`，以及每行列数 1 至 5 |
| `groups` | 两个对象，各有 `label` 和 `leaves`；每个子类有唯一的 `key` 与显示用 `label` |
| `rows` | 每个对象提供 `name` 和 `values`。`values` 按子类 `key` 给出非负数值。名称可用 `\n` 分两行 |
| `rows[].color`、`rows[].avatar` | 可选的总量节点颜色 `#RRGGBB` 和现有头像路径。相对路径以输入文件所在目录为基准 |

```bash
swift 桑基图.swift /临时目录/绘图输入.json /输出目录/桑基图.png
```

```powershell
python .\桑基图.py C:\临时目录\绘图输入.json C:\输出目录\桑基图.png
```

省略输出路径时，`桑基图.png` 写到绘图输入文件旁。Python 依赖见 `requirements.txt`。

## 蜂群图

`蜂群图.swift` 和 `蜂群图.py` 导出 4:3 横版 PNG（2400 × 1800，200 DPI）。版式包含居中的标题和副标题、底部刻度和方向标注、淡色纵向网格、零点虚线及 `#F4F6F8` 背景。macOS 使用 Menlo 和苹方，Windows 使用 Consolas 和微软雅黑。原始数值决定横坐标，Logo 仅在纵向避让。密集并列时缩小 Logo，为底部标注留出空间。

Agent 根据当前指标的取值范围设定横轴，根据指标含义确定左右文案。副标题可按当次需要排列，制图署名可保留放大加粗样式。球队实力、赛程难度和对手伤病运气都可使用这套布局。

输入 JSON 包含 `title` 和 `teams`。每支球队提供三字母缩写 `team` 和数值 `strength`。可选 `xRange` 包含 `min`、`max`，并覆盖全部数值。用 `leftLabel`、`rightLabel` 指定两端文案。副标题可用 `method`、`credit`、`source`、`asOf`，或用 `subtitle` 数组按顺序提供 `label`、`value` 和可选 `style`（`mono` 或 `credit`）。两版都读取现有球队 Logo。

```bash
swift 蜂群图.swift /临时目录/绘图输入.json /输出目录/图表.png
```

```powershell
python .\蜂群图.py C:\临时目录\绘图输入.json C:\输出目录\图表.png
```

省略输出路径时，PNG 写到绘图输入文件旁。

## 球队素材

`素材/LOGO/` 保存 30 支 NBA 球队的 WebP，按球队缩写命名，如 `OKC.webp`。Agent 根据原始表格中的球队标识匹配 Logo，并在本地制图时复用。
